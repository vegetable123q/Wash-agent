# E 模块演示脚本

适用场景：3-5 分钟课程 demo 录屏，重点展示洗衣决策、报告和节水节电省钱价值。

## 0:00-0:30 项目定位

今天展示 WashMate Campus 的洗衣决策和报告模块。它不是单纯解释洗衣标签，而是把个人衣柜、共享洗衣机状态和校园洗衣规则组合起来，生成本次可执行的分桶、模式、烘干、费用和风险报告。

## 0:30-1:10 输入来源

先说明本次演示使用的真实后端数据链路：

- 衣物来自 `data/wardrobe_sample.json`，包含白色 T 恤、黑色牛仔裤、羊毛衫和床单被套。
- 机器状态来自 `data/machines_mock.json`。
- 价格、时间和晾晒规则来自 `config/machine_rules.json`。
- 页面或移动端只负责选择本次要洗的衣物和约束，例如是否允许烘干。

可以强调：E 模块不编造默认价格、机器或材质；缺少必要输入会显式报错。

## 1:10-2:10 分桶决策

展示本次选择：

- 白色纯棉 T 恤
- 黑色牛仔裤
- 浅灰色羊毛衫
- 床单被套

讲解 planner 的输出：

- 羊毛衫进入手洗桶，因为羊毛和高缩水/变形风险不适合共享洗衣机。
- 床单被套进入大件桶，避免普通筒过载导致洗不净和返洗。
- 黑色牛仔裤进入深色标准桶，减少掉色和串色。
- 白色 T 恤进入浅色标准桶。
- 每个桶会给出洗衣液用量，例如标准桶少量、大件桶更多、手洗桶更少。
- 机洗桶会推荐匹配的可用机器和位置，方便用户直接去洗衣房操作。

## 2:10-2:50 烘干与风险

说明烘干策略：

- 如果用户不允许烘干，所有批次自然晾干。
- 即使允许烘干，羊毛、高缩水、高变形或明确不可烘干的衣物也会改为自然晾干。
- 深色高掉色风险衣物会提示不要和浅色混洗。
- 如果校园上下文显示无阳台或通风较弱，自然晾干批次会提示预留更长时间。

这部分体现的是减少缩水、串色、返洗和高温损伤。

## 2:50-3:30 费用、时间和机器环境

展示报告里的费用和时间：

- 标准洗批次按机器规则计费。
- 大件洗批次按大件程序计费。
- 手洗和不可机洗批次不进入共享洗衣机计费。
- 如果预算低于预计费用，planner 不会自动删掉用户选择，而是提示可以推迟非急用标准洗批次。

然后展示机器环境：

- 当前可用机器数量。
- 可用机器位置和类型。
- 排队估算。
- 阳台和通风等晾晒条件。

## 3:30-4:20 节水节电省钱价值

讲解报告中的环保价值：

- 自然晾干减少烘干用电。
- 高风险衣物分开处理，减少串色、返洗和重复用水。
- 床品使用大件批次，减少洗不净后重新洗。
- 少洗牛仔、保护羊毛，也能延长衣物寿命，减少重复购买。

## 4:20-5:00 收尾

最后总结 E 模块交付：

- `backend/laundry/planner.py` 负责洗衣决策。
- `backend/reports/generator.py` 负责用户报告。
- `tests/test_e_module.py` 和 `tests/test_full_integration.py` 验证从衣柜、机器上下文到计划和报告的链路。
- 移动端和本地 API 可以直接消费 `WashReport.sections`、`savings_notes` 和 `risk_notes`。
